# 快速开始

## 公开渠道

> 使用 creator-development，走 public 模式，找 30 位美国 YouTube 家庭安防红人。排除户外运动频道，每个结论附证据。

## Nox

先在本机运行环境安全配置自己的 Nox 凭据，再输入：

> 使用 creator-development，走 nox 模式，找 30 位美国 TikTok 美食红人。任务结束汇报本次 Credit 消耗和剩余量。

不要把凭据粘贴到聊天、文档或命令参数。

## 跳过可选项

> 受众性别这次不需要，请跳过并在覆盖说明里保留记录。

## 安装

从 GitHub 仓库或 `releases/v0.1.1/` 下载稳定包，将其中 `creator-development` 文件夹放入 Agent 的 skills 目录，然后调用 `$creator-development`。
