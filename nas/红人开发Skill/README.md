# 红人开发 Skill

## 能做什么

- 从 YouTube、TikTok、Instagram 发现候选红人；
- 按市场、品类、内容、竞品、品牌安全等要求筛选；
- 区分机器初筛、上下文审核和最终交付；
- 输出账号、主页链接、证据、结论、原因与覆盖缺口；
- Nox 模式结束后汇报本任务 Credit 消耗和剩余量。

## 两种模式

- `public`：默认，使用公开渠道；看不到的数据标为未知。
- `nox`：使用员工自己配置的 Nox 凭据；不会读取或分发 Skill 作者的凭据。

## 最少需要

平台、市场、品类或产品、目标数量、排除条件和交付格式。缺少可选信息时会说明影响；你说不需要后会跳过并保留覆盖说明。

## 边界

不会猜邮箱、隐藏受众数据或 Credit 数字。不会未经授权发私信、邮件、写飞书或创建寄样单。

GitHub 是唯一可编辑源码；本目录保存新人说明和稳定版本。稳定包见 `releases/v0.1.1/`。
