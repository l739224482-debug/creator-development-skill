# v0.1.0

Initial public release of Creator Development.

## Included

- Evidence-backed creator sourcing and review for YouTube, TikTok, and Instagram.
- Default public-source mode and explicit user-owned Nox mode.
- Required/optional missing-input handling with `skipped_by_user` coverage.
- Separate discovery, mechanical screening, contextual review, and delivery counts.
- Nox task Credit settlement: consumed, remaining, method, status, and observation time.
- Secret scanning across working files, Git history, and release archives.
- Chinese department onboarding documents for `/TT营销部-4T/TT营销部AI工作包/AI工具`.

## Security

No runtime credential, account identifier, private proxy, provider cache, or internal creator database is included. Nox users must configure their own compatible credential in their runtime environment.

## Known limits

- Public sources cannot verify hidden audience or private performance metrics.
- Credit usage is reported as unavailable when response-field semantics, isolated snapshots, or remaining balance cannot be verified.
- Outreach, Feishu writes, and sample-order creation require separate authorization.
