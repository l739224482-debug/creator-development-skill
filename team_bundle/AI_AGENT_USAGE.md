# 给同事的 Agent

请先读本包 README.md、WORKFLOW.md 和 ../SKILL.md，再执行用户的红人开发需求。

- 默认公开研究；Nox需本次授权及明确上限。先检查工具安装、凭证类型和免费quota，不输出密钥。
- 通过 `tools/nox.py` 调官方CLI并保留唯一任务账本。不要另起裸CLI绕过预算、无限重试或自动轮换key。
- `examples/brief.json`只是Ascentiz案例模板，所有项目门槛必须以用户实际需求为准。
- `public_tiktok.py`只做公开数据和机械指标，输出保持review，不能自行宣称画像/口播/联系归属通过。
- 口播需要真实音轨+语义核验，音源来自他人时不能冒充本人。要求8/10时不可用3条抽查代替。
- 用户授权飞书写入后，使用本人已授权的飞书Skill/CLI创建交付表并完整回读。工具包不包含Lee的NAS/飞书账号配置或历史红人库。
- 所有最终必须字段都有明确来源，否则review/rejected。用户停止立即停止。记录实际credit和证据缺口。
