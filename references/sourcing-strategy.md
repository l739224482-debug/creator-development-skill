# Sourcing Strategy

Translate the brief into keyword families for product/category, use case, audience, market/language, creator format, and exclusions. Search from several independent seeds:

- category and problem-led queries;
- competitor collaborators and adjacent brands;
- audience-adjacent topics and communities;
- similar accounts from already-qualified seeds;
- a prior seed list, deduped before new discovery.

For every candidate, capture platform, public handle, canonical URL, discovery query/source, and observation date. Treat snippets as discovery clues; open the public profile or authorized provider record before using facts as evidence.

Expand until the requested contextually reviewed count is achieved or useful coverage is exhausted. Report the shortfall and exhausted routes instead of padding the list with weak candidates.
